Declaración de Accesibilidad

1. Etiquetado semántico

Todas las páginas han sido estructuradas empleando elementos semánticos de HTML5 (<header>, <nav>, <main>, <section>, <article> y <footer>), garantizando un orden de lectura lógico y lineal incluso si se desactivan las hojas de estilo.

2. Texto alternativo en imágenes

Todas las imágenes que transmiten información relevante cuentan con el atributo alt descriptivo para que puedan ser interpretadas por lectores de pantalla.

3. Uso correcto de los colores y el contraste

No se utiliza exclusivamente el color para transmitir información. Además, se han verificado las relaciones de contraste entre texto y fondo para cumplir con los estándares AA y AAA de WebAIM.

4. Cómo activar las hojas de estilo accesibles

Este sitio web ofrece varios estilos alternativos pensados para adaptarse a las necesidades visuales de cada usuario:

  • Estilo predeterminado: Diseño base con tonos suaves.
  • Modo noche: Paleta oscura de bajo brillo para reducir la fatiga visual.
  • Alto contraste: Combinación de colores de máximo contraste y enlaces subrayados.
  • Texto grande: Aumento del cuerpo de texto y uso de la tipografía Atkinson Hyperlegible, diseñada por el Braille Institute para personas con baja visión y dislexia.
  • Alto contraste y texto grande: Combinación de ambas mejoras.

Para seleccionar cualquiera de estos estilos desde el navegador Mozilla Firefox, pulsa la tecla Alt para mostrar la barra de menú superior, selecciona Ver → Estilo de página y haz clic en el estilo que desees aplicar.

5. Otras características implementadas

  • Formularios accesibles: Todos los controles disponen de etiquetas <label> asociadas y agrupaciones <fieldset> con su correspondiente <legend>.
  • Tablas accesibles: Uso de <caption> y encabezados con atributo scope.
  • Versión impresa automática: Hoja de estilo adaptada para papel A4 que se activa automáticamente al imprimir la página.
